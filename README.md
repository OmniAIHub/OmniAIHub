# OmniAIHub

**Everything AI. One Hub.**

Open-source AI skills, tools, agent workflows, and developer resources that work with **any** coding agent — Cursor, Claude Code, Copilot, Windsurf, and more.

## Explore
- **[AI Skills](https://github.com/OmniAIHub/ai-skills)** — reusable `SKILL.md` packs (Ghost human writing, Pygame/Ursina games, …)
- **AI Tools** — coming soon
- **Agent Examples** — coming soon

## Quick start
```bash
git clone https://github.com/OmniAIHub/ai-skills.git
```
Copy a folder from `skills/` into your agent's skills path, or `@` / paste a `SKILL.md`. See the [install guide](https://github.com/OmniAIHub/ai-skills/blob/main/INSTALL.md).
